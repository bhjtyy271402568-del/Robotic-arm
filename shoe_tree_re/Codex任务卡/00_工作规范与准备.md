## 一、每一轮都要遵守的规范

1. **不动基准文件。** `01_当前基准/黑壳_螺母侧_双肋与A筋外宽20齐平.SLDPRT` 只读。所有修改另存为新版本，命名：`<零件名>_v<两位轮次>_<日期>.SLDPRT`，例如 `黑套筒_v01_20261129.SLDPRT`。
2. **统一坐标系：用 01 壳的坐标。** X 沿长槽，从后跟销座指向齿轮；Y=0 是合壳面，螺母侧在 −Y；Z 横向，槽中心 Z=−16.5。总装里 01 壳固定在原位，不移动、不旋转。02 参考装配的坐标不同（合壳面 Z=0，机身沿 Y），**不能直接复制位置**，只能参考零件形状。
3. **尺寸来源分三类，写进零件的自定义属性 `尺寸来源`：**
   - `实测`：用户用卡尺量的，写明测量编号（如 S2、G1）；
   - `定版`：交接文件"已确认的尺寸"一节里的；
   - `暂定`：没有依据、为了能装起来先给的值。暂定尺寸必须做成全局变量，放在方程式里，变量名以 `TMP_` 开头。
4. **不为了消除干涉去改定版尺寸。** 双肋、A 筋、小框、左侧壁、B 销孔位置都是定版。干涉了就报告，不要自己挪肋或放大壳体。
5. **每轮交付（推到本仓库 `shoe_tree_re/codex交付/v<轮次>/`）：**
   - 可编辑文件：SLDPRT、SLDASM；
   - 静态 STEP：总装一份（AP214，**每个零件一个实体，零件名用中文原名**），以及各零件散件；
   - 一张截图清单：开壳视图、关键截面；
   - 一个 `说明.md`：本轮改了什么、哪些尺寸是暂定、自己发现的问题。
   Claude 收到后用 `shoe_tree_re/tools/step_check.py` 做干涉、间隙、截面核对，结果写到 `shoe_tree_re/核对报告/`。
6. **装配配合**：同轴、重合、距离这类配合要按真实的机械关系加（比如套筒外圆与 A 弧口同轴是"放在上面"，不是"固定"）。能转的零件只约束轴线和轴向位置，留出转动自由度，方便之后做运动检查。

## 二、本卡任务：试装装配骨架

### 1. 新建总装 `机芯试装_v01.SLDASM`

- 插入 01 基准壳，固定在原点（零件原点与装配原点重合，不加旋转）。
- 建三个参考基准，命名如下，后续零件都配合到它们：

| 基准名 | 定义 | 说明 |
|---|---|---|
| `轴线_套筒` | 过点 (0, 0, −16.5)，方向 +X | 暂按合壳面上的同轴线放（见对照表第一节第 3 条）。A1 弧深量出来后可能要调到 Y=−1.7，所以 Y 值做成变量 `TMP_套筒轴Y = 0` |
| `面_A筋近端` | X = 107.75 的平面 | 定版 |
| `轴线_B销` | 过 B 销孔中心 (6.2, *, 7.6)，方向 +Y | 从 01 壳的 Ø4.2 孔圆柱面取，不要手输坐标 |

### 2. 建占位套筒 `黑套筒_v01.SLDPRT`

尺寸大部分还没量，先做一个能改的参数化占位件：

| 段 | 外径 | 长度 | 来源 |
|---|---|---|---|
| 上端光滑段 | 15 | `TMP_S1 = 30` | 外径定版，长度暂定（待 S1） |
| 螺纹段 | `TMP_S2大径 = 17` | `TMP_螺纹长 = 55` | 暂定（待 S2），先画光圆柱，不画螺纹 |
| 凸环 | `TMP_凸环径 = 20` | `TMP_凸环厚 = 2` | 暂定（待 S3） |
| 凸环以下 | `TMP_S4 = 15` | `TMP_下段长 = 15` | 暂定（待 S4） |
| 内孔 | `TMP_S6 = 8` | 通孔 | 暂定（待 S6） |

装配：外圆与 `轴线_套筒` 同轴；**套筒顶端面**放在 X = 109.75 + `TMP_套筒顶超出A筋`（109.75 是 A 筋靠齿轮一侧的面；变量暂定 = 5，表示套筒顶端越过 A 筋往齿轮方向伸出 5 mm，待实测）。用距离配合实现：套筒顶端面到 `面_A筋近端` 的距离 = 2 + `TMP_套筒顶超出A筋`，方向朝 +X。

### 3. 先报告，不要修

装好后做以下检查，把结果写进 `说明.md`，**发现问题不要改 01 壳**：

1. 在 X = 108.75（A 筋中间）截面：Ø15 外圆和 A 弧口之间的间隙，分别在弧底和两个尖头处各是多少；
2. 在 X = 2.5（下端座）截面：套筒外圆和 Ø18.6 半圆座之间的间隙；
3. 套筒和双肋顶面之间的最小间隙（预期 4–6 mm，肋不接触套筒）；
4. 套筒顶端和小加强框之间有没有干涉；
5. 用 SolidWorks 干涉检查跑一遍总装，列出所有干涉对和体积。

### 4. 交付

按第一节第 5 条推到 `shoe_tree_re/codex交付/v01/`。总装 STEP 命名 `机芯试装_v01.step`。
